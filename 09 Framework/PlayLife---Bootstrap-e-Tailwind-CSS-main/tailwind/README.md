# PlayLife — Tailwind CSS

Esta versão da PlayLife foi desenvolvida utilizando **HTML5 e Tailwind CSS**, como parte da atividade prática de Front-end.

O projeto apresenta uma loja fictícia de jogos, com banner principal, apresentação da loja e uma seção de jogos em destaque, incluindo Minecraft, Mortal Kombat e Mario Kart.

### Tecnologias utilizadas
- HTML5
- Tailwind CSS

### Como executar
1. Abra o arquivo `index.html` em um navegador.
2. Certifique-se de que o Tailwind CSS esteja configurado conforme o método utilizado no projeto e de que os recursos externos estejam acessíveis.

### Objetivo
Praticar a criação de layouts responsivos e personalizados utilizando classes utilitárias do Tailwind CSS.
