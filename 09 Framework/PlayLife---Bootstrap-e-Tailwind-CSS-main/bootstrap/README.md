# PlayLife — Bootstrap

Esta versão da PlayLife foi desenvolvida utilizando **HTML5 e Bootstrap 5**, como parte da atividade prática de Front-end.

O projeto consiste em uma página de uma loja fictícia de jogos, com banner principal, apresentação da loja e uma seção de jogos em destaque, incluindo Minecraft, Mortal Kombat e Mario Kart.

### Tecnologias utilizadas
- HTML5
- Bootstrap 5 via CDN

### Como executar
1. Abra o arquivo `index.html` em um navegador.
2. Certifique-se de estar conectado à internet para carregar o Bootstrap e os recursos externos.

### Objetivo
Praticar a construção de layouts responsivos utilizando componentes e classes predefinidas do Bootstrap.
